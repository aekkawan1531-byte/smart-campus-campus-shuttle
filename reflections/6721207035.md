# Reflection รายบุคคล - การพัฒนา Mini Project Smart Campus Campus Shuttle

**ชื่อ-สกุล:** นายเอกวรรณ จันวงเดือน

**รหัสนักศึกษา:** 6721207035

**กลุ่มที่:** 8 - Campus Shuttle

### 1. AI สามารถช่วยพัฒนาระบบวางแผนการเดินทางให้มีประสิทธิภาพมากขึ้นได้อย่างไร

AI ช่วยในการวิเคราะห์และออกแบบเงื่อนไขการค้นหาเส้นทางรถรับส่งระหว่างจุดต้นทางและปลายทาง โดยช่วยตรวจสอบว่าสายรถที่เลือกผ่านจุดจอดที่ผู้ใช้งานต้องการหรือไม่ รวมถึงช่วยออกแบบการแจ้งเตือนเมื่อไม่พบเส้นทางที่สามารถเดินทางได้ ทำให้ระบบวางแผนการเดินทางมีความสมบูรณ์และสะดวกต่อผู้ใช้งานมากขึ้น

### 2. ปัญหาที่อาจเกิดขึ้นจากการใช้งานระบบวางแผนการเดินทางมีอะไรบ้าง และควรแก้ไขอย่างไร

ปัญหาที่อาจเกิดขึ้น ได้แก่ การเลือกจุดต้นทางและปลายทางเป็นจุดเดียวกัน การค้นหาเส้นทางที่ไม่มีรถให้บริการ และการได้รับข้อมูลเส้นทางที่ไม่ตรงกับความต้องการ AI สามารถช่วยวิเคราะห์เงื่อนไขและเสนอแนวทางแก้ไข เช่น การตรวจสอบข้อมูลก่อนประมวลผลและการแสดงข้อความแจ้งเตือนเป็นภาษาไทย เพื่อให้ผู้ใช้งานเข้าใจปัญหาได้อย่างชัดเจน

### 3. จากการศึกษาโครงการ Campus Shuttle สามารถนำความรู้ด้านใดไปประยุกต์ใช้ในการพัฒนาระบบอื่นได้บ้าง

จากการศึกษาโครงการทำให้เข้าใจการทำงานร่วมกันของ HTML, CSS และ JavaScript มากขึ้น โดยเฉพาะการรับข้อมูลจากผู้ใช้งาน การตรวจสอบเงื่อนไข การประมวลผลข้อมูล และการแสดงผลบนเว็บไซต์ รวมถึงการจัดการข้อผิดพลาดที่อาจเกิดขึ้นระหว่างการใช้งาน ซึ่งสามารถนำความรู้ไปประยุกต์ใช้ในการพัฒนาระบบสารสนเทศอื่นได้
